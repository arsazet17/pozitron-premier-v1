# Позитрон Премьер — v1.0.0

PWA для GitHub Pages: AI-ставка 4+4 на следующий тираж лотереи «Премьер» (Национальная Лотерея).
Расчёт выполняется в GitHub Actions (`Premier Auto Update`), браузер только показывает готовый `data/app-state.json`.

## Лотерея

Два поля, в каждом 4 числа из 20. Тираж каждые 15 минут (:08, :23, :38, :53 по Москве), билет 50 ₽, призовой фонд 70%.
Выплаты из раздела «Как играть → Условия победы»:

| Поле 1 + Поле 2 | Выигрыш |
|---|---|
| 4 + 4 | суперприз (делится между победителями) |
| 4 + 3, 3 + 4 | 50 000 ₽ |
| 4 + 2, 2 + 4 | 10 000 ₽ |
| 4 + 1, 1 + 4 | 5 000 ₽ |
| 4 + 0, 0 + 4 | 1 000 ₽ |
| 3 + 3 | 750 ₽ |
| 3 + 2, 2 + 3, 3 + 1, 1 + 3, 3 + 0, 0 + 3, 2 + 2 | 500 ₽ |

Выиграть хоть что-то — 1 из 20,5 (4,87%). Средний возврат фиксированных выигрышей — 26,20 ₽ с билета (52,4%).

## Как работает AI

8 методов на каждое поле: 🔥 Горячие, 🧊 Холодные, 🔁 Повторы, ↔️ Соседи, 🧭 Переходы, 🔀 Перекрёст, 🪞 Зеркало, 🎵 Ритм.
После каждого тиража у метода считается, сколько из его 4 чисел выпало (случайно — 0,80). Кто угадал больше — получает больший вес.
Память — около 33 последних тиражей. Ставка — 4 числа с наибольшей суммой голосов методов.

Настройки (скорость реакции весов и память) подобраны на тиражах 1–20 000 и проверены на 20 001–30 487.

## Проверка по архиву (30 437 ставок, без подглядывания)

| | AI | Случайная ставка |
|---|---|---|
| Угадано чисел в среднем | 0,804 / 0,805 | 0,800 / 0,800 |
| Выигрышей | 1 498 | ≈ 1 483 |
| Выплачено | 812 250 ₽ | ≈ 797 466 ₽ |
| Возврат | 53,4% | 52,4% |

Разница в пределах обычного случайного разброса: архив ведёт себя как честный лототрон.

## Цикл (каждые 15 минут)

1. Скачать страницу Lucky-numbers (20 последних тиражей) и добавить новые в архив.
2. Проверить зафиксированные ставки (попадания, выплата).
3. Прогнать AI по всему архиву «вперёд» и зафиксировать ставку на следующий тираж. Уже зафиксированная ставка не меняется, задним числом ставка не создаётся.

## Запуск через cron-job.org

- URL: `https://api.github.com/repos/arsazet17/pozitron-premier-v1/actions/workflows/premier-auto-update.yml/dispatches`
- Метод: `POST`, тело: `{"ref":"main"}`
- Заголовки: `Authorization: Bearer <токен>`, `Accept: application/vnd.github+json`, `X-GitHub-Api-Version: 2022-11-28`
- Расписание: каждый час в минуты 12, 27, 42, 57.

## Файлы данных

- `data/premier-archive.csv` — архив тиражей (формат Lucky-numbers).
- `data/current-forecast.json` — ставка на ближайший тираж.
- `data/forecast-history.json` — все зафиксированные ставки с результатом.
- `data/app-state.json` — всё, что показывает приложение.
- `data/lottery-meta.json` — суперприз и цена билета.
